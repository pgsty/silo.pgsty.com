**版本：** [RELEASE.2026-10-18T00-00-00Z](https://github.com/pgsty/mc/releases/tag/RELEASE.2026-10-18T00-00-00Z) · **包版本：** `20261018000000.0.0` · **源码：** [`fa3b8bf72458`](https://github.com/pgsty/mc/commit/fa3b8bf72458b9b5480c4da0ce63a4f224e058c8)。

本次发布标识为 20261018，实际于 2026 年 10 月 17 日完成发布。

## 更新内容 {#changes}

- 使用 **silo-pkg v3.14.2** 和上游 **minio-go v7.4.1**。SDK 修复取消后的失败分段上传清理、保留时间 UTC 格式及 STS 时长传递，保留现有 CopyObject 内嵌错误和校验和处理。并行 GET 与 ComposeObject 仍需显式启用。
- 使用 **Go 1.27.2** 构建，更新 Go x/* 模块、compress **v1.20.3**、msgp **v1.6.5** 和 etcd 客户端 **v3.7.2**。fwd **v1.2.1** 修复同时返回数据和错误时的数据丢失及 Skip 偏移；cpuid **v2.4.1** 修复缓存识别。
- 通过 silo-pkg 引入 go-jose **v4.1.6** 和 LDAP **v3.4.15**。go-jose 的 JWK RSA 大小限制修复 [GHSA-mgcc-cww5-fp2q](https://github.com/go-jose/go-jose/security/advisories/GHSA-mgcc-cww5-fp2q)。
- 刷新固定摘要的 UBI 9 基础镜像与发布工具：GoReleaser **v2.18.3**、nFPM **v2.48.0**、golangci-lint **v2.15.0**、govulncheck **v1.9.0** 和 gofumpt **v0.12.0**。GoReleaser 包含日志敏感信息遮蔽及归档、发布正确性修复。

## 升级说明 {#upgrade}

命令、别名、`MC_*` 变量与配置格式不变。go-systemd 保留 **v22.6.0** 替换以支持 NetBSD 构建，tablewriter 保留 **v0.0.5** API。升级 mcli 不会改变已安装的 Server、Console，也不会替换旧 Server 镜像内置的客户端。参见[组件版本表](/zh/compatibility/versions/)。

正式支持的管理集成目标是 SILO；与未修改的上游 MinIO 及其他 S3 服务的兼容性为尽力支持。

```sh
docker run --rm docker.io/pgsty/mc:RELEASE.2026-10-18T00-00-00Z --version
```
