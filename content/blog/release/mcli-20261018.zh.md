**版本：** [RELEASE.2026-10-18T00-00-00Z](https://github.com/pgsty/mc/releases/tag/RELEASE.2026-10-18T00-00-00Z) · **软件包版本：** `20261018000000.0.0` · **源码：** [`fa3b8bf72458`](https://github.com/pgsty/mc/commit/fa3b8bf72458b9b5480c4da0ce63a4f224e058c8)。

本版本作为独立 `mcli` 客户端及 [Server 20261018](/zh/blog/release/silo-20261018/#components) 与 [Console v2.4.2](/zh/blog/release/console-2.4.2/) 的配套客户端版本发布（参见 [silo-pkg v3.14.2 发布说明](/zh/blog/release/pkg-3.14.2/)）。

## 更新内容 {#changes}

- 升级至 **silo-pkg v3.14.2** 与上游 **minio-go v7.4.1**。SDK 修复取消后的失败分段上传清理、UTC 保留期时间戳格式及 STS 时长透传，并保留既有 `CopyObject` 内嵌错误处理与校验和逻辑（并行 GET 与 ComposeObject 仍需显式启用）。
- 使用 **Go 1.27.2** 构建，更新 `golang.org/x/*` 模块、compress **v1.20.3**、msgp **v1.6.5** 与 etcd 客户端 **v3.7.2**（其中 fwd **v1.2.1** 修复同时返回数据与错误时的字节丢失及 `Skip` 偏移；cpuid **v2.4.1** 修复缓存识别）。
- 通过 `silo-pkg` 引入 go-jose **v4.1.6**（修复 RSA JWK 解析 CPU 消耗问题 [GHSA-mgcc-cww5-fp2q](https://github.com/go-jose/go-jose/security/advisories/GHSA-mgcc-cww5-fp2q)）与 LDAP **v3.4.15**。
- 刷新固定摘要的 UBI 9 基础镜像与发行工具链：GoReleaser **v2.18.3**（含日志脱敏与归档修复）、nFPM **v2.48.0**、golangci-lint **v2.15.0**、govulncheck **v1.9.0** 与 gofumpt **v0.12.0**。

## 升级说明 {#upgrade}

CLI 命令、别名、`MC_*` 环境变量与本地配置文件格式保持不变（保留 go-systemd **v22.6.0** 替换以支持 NetBSD 构建，保留 tablewriter **v0.0.5** API）。各组件配套关系见[组件版本矩阵](/zh/compatibility/versions/)。

```sh
docker run --rm docker.io/pgsty/mc:RELEASE.2026-10-18T00-00-00Z --version
```
