**Release:** [RELEASE.2026-10-18T00-00-00Z](https://github.com/pgsty/mc/releases/tag/RELEASE.2026-10-18T00-00-00Z) · **Package:** `20261018000000.0.0` · **Source:** [`fa3b8bf72458`](https://github.com/pgsty/mc/commit/fa3b8bf72458b9b5480c4da0ce63a4f224e058c8).

`mcli 20261018` ships both as the standalone CLI client and as the coordinated client module in [Server 20261018](/blog/release/silo-20261018/#components) and [Console v2.4.2](/blog/release/console-2.4.2/) (see also the [silo-pkg v3.14.2 release notes](/blog/release/pkg-3.14.2/)).

## Changes {#changes}

- Adopt **silo-pkg v3.14.2** and upstream **minio-go v7.4.1**. The SDK cleans up failed multipart uploads after cancellation, formats retention timestamps in UTC, and preserves requested STS durations while retaining existing `CopyObject` embedded-error and checksum handling (parallel GET and ComposeObject remain opt-in).
- Build with **Go 1.27.2**. Refresh `golang.org/x/*` modules, compress **v1.20.3**, msgp **v1.6.5**, and etcd clients **v3.7.2** (with fwd **v1.2.1** fixing reads that return bytes alongside an error as well as `Skip` offsets, and cpuid **v2.4.1** fixing cache detection).
- Pull in go-jose **v4.1.6** (fixing excessive CPU usage on oversized RSA JWKs in [GHSA-mgcc-cww5-fp2q](https://github.com/go-jose/go-jose/security/advisories/GHSA-mgcc-cww5-fp2q)) and LDAP **v3.4.15** via `silo-pkg`.
- Refresh pinned UBI 9 base images and release tooling: GoReleaser **v2.18.3** (including log secret redaction and archive fixes), nFPM **v2.48.0**, golangci-lint **v2.15.0**, govulncheck **v1.9.0**, and gofumpt **v0.12.0**.

## Upgrade {#upgrade}

CLI commands, aliases, `MC_*` environment variables, and configuration formats are unchanged (retaining the go-systemd **v22.6.0** replacement for NetBSD builds and tablewriter **v0.0.5**). See the [component matrix](/compatibility/versions/) for version pairings.

```sh
docker run --rm docker.io/pgsty/mc:RELEASE.2026-10-18T00-00-00Z --version
```
