**状态：本地验收与托管 CI 均通过，已准备好发布，尚未正式发布。** 已创建本地签名 Git 标签 `RELEASE.2026-10-25T00-00-00Z`，软件包版本为 `20261025000000.0.0`。[下载页](/zh/download/#client)继续提供已发布的 [20261018 版本](/zh/blog/release/mcli-20261018/)。本客户端属于 [20261025 统一维护批次](/zh/blog/release/silo-20261025/)。

## 相对 20261018 的变更 {#changes}

- 采用 **Go 1.27.3** 与 **silo-pkg v3.15.1**，保留共享包的策略判定优化与既有授权语义，刷新 Prometheus、etcd、gRPC、JWX、JSON 和终端相关依赖。Go 证书信任修复及发行容器根证书阻止列表见[统一维护公告](/zh/blog/release/silo-20261025/#go-trust)。
- 使用上游 **minio-go `v7.4.2-0.20261020194015-ab93db7ba435`**。这是 v7.4.1 之后的固定上游提交，并非正式 v7.4.2。顺序与并行分段上传遇到截短输入会失败，避免完成短对象；单对象删除回退失败只报告一次错误。SDK 同时修复 `ReadAt` 的 EOF 与负偏移处理，以及 `Stat` 之后的读/seek 边界。并行 SDK GET 仍需显式启用。
- 支持别名配置中持久化的可选 `region`，优先级为 `MC_REGION`、`AWS_REGION`、别名配置；未设置时继续查询桶所在区域。客户端缓存区分签名区域。本次没有增加 `alias set --region` 参数。
- `admin info --json` 失败时返回**非零退出码**，同时保留原有 JSON 错误记录。20261018 在权限被拒绝时可能输出 `status: error`，但仍返回成功退出码。
- Windows `amd64`、`arm64` 归档改用 **ZIP**；Linux 与 macOS 保留 **tar.gz**。发布检查覆盖归档格式、随包文档、校验和与二进制源码标记。
- 明确禁用的服务端更新与 SUBNET 命令说明，改进 SQL 示例和 SILO 帮助链接。CI 功能测试采用固定校验和的 SILO 20261018。

## 升级注意事项 {#upgrade}

正式维护和验收的服务端是 **pgsty/silo**。对未经修改的上游 MinIO 及其他 S3 服务保留尽最大努力的兼容性。本次客户端更新不要求同步升级 Server 或 Console。

继续支持既有 CLI 配置与 `MC_*` 环境变量。保留 go-systemd v22.6.0 的 NetBSD 兼容性选择、go-runewidth v0.0.29 的终端宽度行为和 tablewriter v0.0.5 API。自动下载 Windows 制品的脚本需为本版本选择 `.zip`。

CLI 分段上传被 SIGINT 中断时退出码为 130，可能留下未完成分片，与 20261018 一致；不会暴露已完成对象。需要时清理对应前缀：

```sh
mcli rm --incomplete --recursive --force ALIAS/BUCKET/PREFIX
```

下载响应体中途断开时命令返回失败，需要重试；客户端不能把截短下载报告为成功。

## 验收与交付状态 {#validation}

本地验收覆盖当前 SILO 与已发布的 20261018，包含 HTTP 和可信 TLS 下的 Go/Shell 功能套件，SSE-S3、SSE-C 与专用测试 KMS 密钥，版本管理、Object Lock、复制、IAM、STS、失败复制的源文件保护、部分镜像失败、持续镜像历史、SQL 及网络故障恢复。全量单元测试与 race 检测、静态检查、漏洞扫描和全部 262 个可见命令帮助页面均通过。六个归档、六个 Linux 软件包和两种 Linux 容器架构通过本地检查；六种软件包均完成 20261018 安装、升级至 20261025、回退和卸载，并验证客户端配置保留。日志与私有测试材料保存在公共仓库之外。

本地运行覆盖原生 macOS arm64、Linux arm64，以及模拟执行的 Linux amd64；托管 CI 还通过了 Windows amd64、macOS arm64 和 Linux amd64 的原生测试。Windows arm64 与 macOS amd64 在本轮仍只有交叉编译验证。服务端测试使用单节点、四个数据目录，不能替代生产多节点故障验收。文件属性保留用例按读取前的快照核验，并覆盖 Linux 上读取上传源文件导致访问时间更新的情况。

候选源码提交为 [`dcc78d506f94`](https://github.com/pgsty/mc/commit/dcc78d506f94e7c2323b642d48fbb600664f0586)。发行制品从该提交的干净本地签名标签构建，标签签名与二进制源码标记均已验证。标签尚未推送。
