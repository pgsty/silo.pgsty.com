## 相对 20260903 的变化 {#changes}

- `mirror --remove --watch` 保留目标端历史版本。
- 服务重启的 dry run 只显示计划，不执行重启；明确非交互环境行为。
- 传输与 S3 Select 出错时返回失败；空上传遵守显式校验和参数；quiet 模式下仍输出 `pipe` JSON。
- 布尔环境变量接受 on/off，修复跨平台 CLI/JSON 行为。
- 使用 [pkg v3.14.0](/zh/blog/release/pkg-3.14.0/) 与上游 SDK `v7.3.1-0.20260910142817-60bd07042d49`，刷新 Go x/*、UBI 依赖，保留 Go 1.27.1。NetBSD 继续固定 go-systemd v22.6.0。

保留 pkg v3.13.3 引入的 Deny/NotResource 与有界通配匹配修复。
正确保留的 Deny 可能拒绝曾依赖丢失语句而成功的请求；已经丢失的语句仍需从原始策略恢复。

新 pkg 还改变密码能力。协调升级 Server 前请阅读[密码策略迁移](/zh/compatibility/password-permissions/)。
只安装新版 mcli 不会改变已安装 Server 的动作映射。截至 2026-09-13，配套 Server/Console 改动尚未正式发布，
详见[组件版本矩阵](/zh/compatibility/versions/)。

## 制品与验证 {#delivery}

归档与校验清单已核验构建证明，RPM 携带 PGSTY GPG 签名；macOS arm64 原生执行版本输出与 Go 构建信息已核对。
