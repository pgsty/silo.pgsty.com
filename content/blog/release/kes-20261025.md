**KES 20261025000000 is released.** The [GitHub release](https://github.com/pgsty/kes/releases/tag/RELEASE.2026-10-25T00-00-00Z) uses tag `RELEASE.2026-10-25T00-00-00Z`, package version `20261025000000.0.0`, and source commit [`b0a98d87f656`](https://github.com/pgsty/kes/commit/b0a98d87f6564c1a6d9584c0a5260910a731f66d). Published on October 26 as part of the [October 25 maintenance batch](/blog/release/silo-20261025/), its archives and packages are linked on the [download page](/download/#kes), and the matching multi-arch Docker Hub image (`linux/amd64` and `linux/arm64`) is published under both the release tag and `latest`.

## Toolchain and dependencies {#dependencies}

Compared with KES 20261018, this release upgrades Go from **1.27.2 to 1.27.3**, updates **25 required modules**, and switches Windows release archives to `.zip`:

| Dependency | Published KES 20261018 | 20261025 |
| --- | --- | --- |
| AWS SDK v2 core | 1.47.3 | **1.47.4** |
| AWS SDK config / credentials | 1.33.9 / 1.20.9 | **1.33.10 / 1.20.10** |
| AWS Secrets Manager | 1.50.4 | **1.50.6** |
| Google Secret Manager | 1.22.0 | **1.23.0** |
| Google API / IAM | 0.304.0 / 1.14.0 | **0.308.0 / 1.15.0** |
| Google certificate proxy / GAX | 0.3.23 / 2.26.2 | **0.3.24 / 2.27.0** |
| HashiCorp go-rootcerts | 1.0.2 | **1.1.0** |
| Prometheus procfs | 0.22.0 | **0.23.0** |

The remaining updates cover AWS supporting modules and three Google generated API modules. The October 25 audit and October 26 rescan checked all **26 direct and 76 indirect requirements** along with 93 additional modules in the module graph; every declared requirement is at the latest version on its current module path.

Lip Gloss v1 and `gopkg.in/yaml.v3` remain at their compatible versions (moving to Lip Gloss v2 or switching YAML module paths requires separate terminal output and configuration migration checks). This release does not change the KES HTTP API, configuration schema, or stored key format.

## Security and packaging {#security}

Go 1.27.3 includes the `crypto/x509` certificate-verification fix for **CVE-2026-111943 / GO-2026-6809**, detailed in the [shared security notes](/blog/release/silo-20261025/#go-trust). The container build recipe refreshes the UBI 9.8 base digests and applies the root certificate blocklist; external services whose certificates still chain to those blocked roots will fail TLS verification, as noted in the [shared certificate notes](/blog/release/silo-20261025/#local-mitigations).

Source scans with govulncheck 1.9.0 across Linux, macOS, and Windows found no vulnerable imported packages (`GO-2026-5932` remains a module-level record on unimported OpenPGP packages in `golang.org/x/crypto`). Base-image package notes are tracked in the [shared UBI notes](/blog/release/silo-20261025/#ubi-residuals).

The release pipeline upgrades GoReleaser from **2.18.3 to 2.19.0** ([release notes](https://github.com/goreleaser/goreleaser/releases/tag/v2.19.0) include Go 1.27.3, dependency security updates, and archive error handling fixes); nFPM remains at **2.48.0**, built in CI with the Go toolchain specified in `go.mod`.

Linux and macOS archives use `.tar.gz`, while Windows archives use `.zip`. The release provides six platform archives and six Linux RPM/DEB/APK packages; Linux packages install `/usr/local/bin/kes` without starting an unconfigured service.

## Release checks {#validation}

Source [`b0a98d87f656`](https://github.com/pgsty/kes/commit/b0a98d87f6564c1a6d9584c0a5260910a731f66d) passed the [Go](https://github.com/pgsty/kes/actions/runs/40257613627), [VulnCheck](https://github.com/pgsty/kes/actions/runs/40257613658), [KMS Compatibility](https://github.com/pgsty/kes/actions/runs/40257613681), and [Test Release Pipeline](https://github.com/pgsty/kes/actions/runs/40257613626) workflows before tagging, alongside local Go race tests, vet, lint, module integrity, and release guard checks (cloud KMS backends are tested against local protocol fixtures).

The [Release workflow](https://github.com/pgsty/kes/actions/runs/40258161919) produced six platform archives, six Linux packages, and checksum manifests (19 release assets in total). The release tag and both RPMs are signed with the Pigsty OpenPGP key; GitHub build attestations cover the archives, checksum manifest, DEBs, and APKs. Downloaded binary versions, clean source stamps, dependency versions, package payloads, and license files were verified before publication.

The compatibility matrix covers OpenBao KV v2 and Moto Secrets Manager with SILO **20261018, 20260916, and 20260903** (as well as the **SILO 20261025 Draft** and released **mcli 20261025** binaries). OpenBao checks upgrade from the attested PGSTY KES 20261018 release binary, and Moto checks retain the PGSTY AWS SDK v1 baseline. Both fixtures test upgrade, rollback, and cold restart while restarting SILO at each transition to flush cached keys; objects encrypted before and after the upgrade decrypted cleanly across rollback and cold restarts, and stored keys remained intact after test cleanup.

KES uses `master` as its default release branch, with `main` synchronized to the same commit.


Public image downloads were checked against the release binaries, source and version labels, license files, unprivileged `1000:1000` user, and certificate bundle. Both images report the expected version and Go 1.27.3. Pin the release tag or digest for deployments:
