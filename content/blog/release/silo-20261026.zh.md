## Server：自 20261018 以来的修改 {#server-20261026}

<span id="server-20261025"></span><span id="changes"></span>

- **LDAP 与 IAM：** 修复规范化 LDAP DN 过长时无法登录的问题，同时不隐藏无法读取的吊销记录（[#250](https://github.com/pgsty/silo/pull/250)）。仅对合法 IAM key 中超过 255 字节的 ASCII 路径分量按记录不存在处理；对象后端仍不支持写入过长记录。策略重载在存储访问期间释放认证缓存锁，仅在完整加载成功后替换缓存，并保留 IAM 写入顺序；请求取消传播到 KMS 与 SSE-S3 解密，不缩短调用者的策略查询期限。
- **内置策略与桶清单：** Reset 后首次读取即可得到原生策略；迟到的 peer/etcd 通知重载已提交状态，不覆盖后续修改。策略使用检查、删除修订与自定义策略删除继续有效。Account-info 读取实时桶清单，成功创建或删除桶后刷新即可看到结果；对象用量仍来自扫描器。
- **多池删除：** 普通或批量清理失败时保留权威副本，为新删除标记选择可用池，并保护仍被其他副本引用的远端分层对象（[#257](https://github.com/pgsty/silo/pull/257)、[#256](https://github.com/pgsty/silo/issues/256)）。这不引入严格的跨池读取恢复。
- **生命周期过期：** 过期操作仅添加删除标记时保留远端分层载荷，包括暂停版本控制桶中的非 null 版本；旧版本只有在被永久删除、且无保留引用需要其载荷后才清理远端数据（[#253](https://github.com/pgsty/silo/pull/253)、[#252](https://github.com/pgsty/silo/issues/252)）。
- **分片复制：** 转发 CRC 分片副本的 `FULL_OBJECT` 校验和类型，避免目标端返回 `BadDigest`（[#255](https://github.com/pgsty/silo/pull/255)、[#254](https://github.com/pgsty/silo/issues/254)）。
- **存储 RPC 与超时兼容：** 转发删除选项，包括覆盖回滚所需的旧数据目录。保留既有磁盘/RPC 期限、取消、对象锁、读仲裁与自愈策略。正式版撤回草稿中的已接纳 I/O 排空等待和 mutation guard 方案（包括 [#258](https://github.com/pgsty/silo/pull/258)），不承诺按所有权隔离回滚或阻止所有迟到提交。见[最终维护调整](https://github.com/pgsty/silo/commit/dcc2f20ba)和[故障边界](/zh/blog/design/multi-pool-object-consistency/#maintenance-20261026)。
- **依赖与交付：** 更新 SFTP、etcd、NATS、云 SDK 等 Go 依赖；保留 Kafka 2.1 默认协议、CLI 格式与 NetBSD 兼容选择；修复旧 DARE v1 解封装，继续使用 v2 写入。镜像、校验安装器和 Helm 客户端任务采用 mcli 20261026。Windows 使用 ZIP，静态 curl 更新为 8.23.0，并应用下文的证书信任缓解；修正最终 SBOM/来源证明刷新时的 RPM 签名身份校验。
- **文档：** 纳入单节点 MinIO 迁移指南（[#228](https://github.com/pgsty/silo/pull/228)），校准运维默认值，并将维护的升级说明统一到[迁移入口](/zh/compatibility/migration/)。

本版继承 [20261018](/zh/blog/release/silo-20261018/) 已交付的 Object Lock、IAM 授权、持久 STS 吊销、迁移与列表修复。下方依赖安全清单分别记录本批次采用的修复、历史修复与未使用代码中的扫描发现。

## mcli：自 20261018 以来的修改 {#mcli}

- **身份隔离：** S3 与管理客户端缓存按凭据、信任、代理、解析器和请求头配置隔离，同时保留凭据刷新和 token 文件轮换（[#50](https://github.com/pgsty/mc/issues/50)、[#55](https://github.com/pgsty/mc/pull/55)）。
- **Resync 状态：** 完整消费 JSON 流直至终态，保留已完成任务的状态输出；明确报告复制已禁用，TTY 在 Failed/Canceled 状态停止等待；修复累计传输约 8.6 GiB 后吞吐量整数溢出（[#48](https://github.com/pgsty/mc/issues/48)、[#49](https://github.com/pgsty/mc/issues/49)、[#52](https://github.com/pgsty/mc/issues/52)）。
- **准确的操作结果：** resync 启动/取消部分失败时保留逐桶错误并返回非零退出码（[#51](https://github.com/pgsty/mc/issues/51)）；成功查询一个已 Failed/Canceled 的任务仍退出零。`admin info --json` 请求失败时也返回非零，同时保留 JSON 错误输出。
- **Batch 观察：** 没有实时指标时继续观察，新增 `pending` JSON 状态，以有界方式回退读取持久状态，避免超大对象计数造成 IOPs 溢出（[#53](https://github.com/pgsty/mc/issues/53)、[#54](https://github.com/pgsty/mc/issues/54)）。
- **别名区域：** 遵循 `MC_REGION`、`AWS_REGION`、持久别名 `region`、自动发现的优先级，并隔离签名区域缓存（[#44](https://github.com/pgsty/mc/pull/44)）。未新增 `alias set --region` 参数。
- **SDK：** 拒绝过短的顺序/并行分片流；修复 `ReadAt` 的 EOF、负偏移和 `Stat` 后读取/seek 边界；去重批量删除回退错误；移除桶复制配置接受 HTTP 200/204，403 等真实错误仍返回错误。
- **打包与帮助：** Go 1.27.3、GoReleaser 2.19.0、Windows ZIP（[#45](https://github.com/pgsty/mc/issues/45)）；更新帮助链接以及禁用的 server-update/SUBNET 命令提示。保留既有 CLI 配置与 `MC_*` 变量。

自动化脚本应处理 `pending` 和部分修改失败的非零退出码；客户端更新无需改变 Server 协议。下载中断仍返回失败；分片上传被 SIGINT 中断时退出 130，可能需要显式清理未完成分片。[完整客户端历史](https://github.com/pgsty/mc/compare/RELEASE.2026-10-18T00-00-00Z...RELEASE.2026-10-26T00-00-00Z)。

## 升级与故障边界 {#upgrade}

1. 备份 IAM 状态、配置与加密密钥，按[升级指南](/zh/operations/replication/iam-upgrade/)协调 Server 进程与复制站点。仍不支持新旧进程共用 IAM 后端或滚动降级。
2. 验证 LDAP/OIDC 登录、内置策略 Reset、桶清单刷新、版本读取、复制与加密对象解密。`FULL_OBJECT` 修复需要升级发送端，然后检查待复制队列。
3. 新版 Windows 归档使用 ZIP，Linux/macOS 保持 tar.gz；脚本适配 mcli 的 `pending` 与部分失败退出码。既有配置名称与存储格式继续支持。
4. 保留此前的分片限制：公开列表仍为节点缓存/精确 key 查找，已退休的 strict 开关被忽略。[#79](https://github.com/pgsty/silo/issues/79) 和 [#217](https://github.com/pgsty/silo/issues/217) 未宣告修复；webhook 热重载 [#249](https://github.com/pgsty/silo/pull/249) 未纳入，较广泛的性能问题 [#251](https://github.com/pgsty/silo/issues/251) 仍开放。

**返回超时不代表底层 I/O 已停止，也不代表写入没有提交。** 部分故障、租约丢失或网络分区后仍可能发生迟到提交、延迟回滚和旧值/标签读取。本版不提供分布式 fencing，不能恢复此前丢失的对象、分层载荷或元数据。后续无条件 PUT 不能证明它已排在尚未解决的请求之后。

### Go 与证书信任 {#go-trust}

**[CVE-2026-111943 / GO-2026-6809](https://pkg.go.dev/vuln/GO-2026-6809)**：Go 1.27.3 在 `crypto/x509` 证书链校验中直接拒绝已知失信的中间证书，在操作系统信任库尚未更新时也能提供兜底拦截。五个主项目及全部独立调试工具均统一使用 Go 1.27.3 编译。

此外，SILO、mcli 与 KES 的 UBI 容器信任库已应用 [Red Hat RHSB-2026-012](https://access.redhat.com/security/vulnerabilities/RHSB-2026-012) 的根证书封禁列表。由于根级封禁会一并拒绝挂靠在这些根证书之下的所有证书链，其拦截范围比 Go 1.27.3 的中间证书黑名单更广；若外部服务仍使用受影响根证书签发的证书链，需先行更换证书。发行版 CA 软件包的跟进状态见下文[本地缓解](#local-mitigations)。
