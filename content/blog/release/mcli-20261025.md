**Released on 2026-10-25.** The signed Git tag is [`RELEASE.2026-10-25T00-00-00Z`](https://github.com/pgsty/mc/releases/tag/RELEASE.2026-10-25T00-00-00Z), and the package version is `20261025000000.0.0`. The [downloads page](/download/#client) provides platform archives, Linux packages, and Docker images. This client is part of the [20261025 maintenance batch](/blog/release/silo-20261025/).

## Changes since 20261018 {#changes}

- Build with **Go 1.27.3** and **silo-pkg v3.15.1**, retaining shared policy evaluation improvements and existing authorization semantics while refreshing Prometheus, etcd, gRPC, JWX, JSON, and terminal dependencies. Go certificate-trust fixes and the release container root blocklist are covered in the [maintenance announcement](/blog/release/silo-20261025/#go-trust).
- Upgrade to upstream **minio-go `v7.4.2-0.20261020194015-ab93db7ba435`** (a pinned post-v7.4.1 upstream commit): truncated sequential and parallel multipart streams now fail immediately instead of completing a short object, a failed single-delete fallback reports one error result, and `ReadAt` EOF/negative-offset handling and post-`Stat` read/seek bounds are fixed (parallel SDK GET remains opt-in).
- Honor the optional `region` field in persisted alias configuration (`MC_REGION`, then `AWS_REGION`, then the alias configuration, falling back to bucket-location discovery when unset). Client caching isolates signing regions. This release does not add an `alias set --region` CLI flag.
- Return a **nonzero exit status** when `admin info --json` fails while preserving its JSON error output (in 20261018, access denial could print `status: error` with exit status `0`).
- Package Windows `amd64` and `arm64` archives as **ZIP** while keeping **tar.gz** for Linux and macOS. Release checks verify archive formats, bundled documents, checksums, and binary source stamps.
- Clarify disabled server-update and SUBNET command messages, SQL examples, and SILO help links. CI functional tests use the checksum-pinned SILO 20261018 release.

## Upgrade considerations {#upgrade}

The maintained server target is **pgsty/silo**, with best-effort compatibility for upstream MinIO and other S3 services. This client update does not require a coordinated Server or Console upgrade.

Existing CLI configuration and `MC_*` environment variables remain supported, retaining `go-systemd v22.6.0` (NetBSD compatibility), `go-runewidth v0.0.29` (terminal column widths), and the `tablewriter v0.0.5` API. Scripts that automate Windows downloads must switch to `.zip` archives starting with this release.

`SIGINT` during a CLI multipart upload exits with status `130` without exposing a completed object, though incomplete upload parts may remain (as in 20261018). Clean up the prefix when needed:

```sh
mcli rm --incomplete --recursive --force ALIAS/BUCKET/PREFIX
```

A download interrupted mid-stream returns a nonzero exit status; retry the command to fetch the complete object.

## Acceptance and delivery {#validation}

Local acceptance against current SILO source and the published 20261018 Server release (single node, four data directories) covers the Go and Shell functional suites over HTTP and trusted TLS; SSE-S3, SSE-C, and a dedicated test KMS key; versioning, Object Lock, replication, IAM, and STS; failed-copy source preservation, partial mirror failures, watch-mode history, SQL, and network fault recovery. Unit tests with `-race`, static analysis, vulnerability scans, and all 262 visible command help pages pass. The filesystem-attribute test compares the pre-read snapshot to handle Linux `atime` updates when reading the upload source. All six archives, six Linux packages, and both Linux container architectures pass local checks, including full `20261018 -> 20261025` install, upgrade, rollback, and uninstall verification across all six Linux package variants with client configuration preserved. Local runs cover native macOS arm64, Linux arm64, and emulated Linux amd64; hosted CI passes native tests on Windows amd64, macOS arm64, and Linux amd64 plus cross-compilation checks for Windows arm64 and macOS amd64.

The release source is [`dcc78d506f94`](https://github.com/pgsty/mc/commit/dcc78d506f94e7c2323b642d48fbb600664f0586). The signed tag is fixed to this commit, and GitHub's [Release workflow](https://github.com/pgsty/mc/actions/runs/40187476316) built the final artifacts from that tag.

**Release gate passed (4/4):** [Go](https://github.com/pgsty/mc/actions/runs/40186055887), [Crosscompile](https://github.com/pgsty/mc/actions/runs/40186055839), [VulnCheck](https://github.com/pgsty/mc/actions/runs/40186055833), and [Test Release Pipeline](https://github.com/pgsty/mc/actions/runs/40186055892) all succeeded on `main`, and the pre-build release gate verified that the tagged commit was the tip of `main`.
