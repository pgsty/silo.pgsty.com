**KES 20261025000000 已发布。** [GitHub Release](https://github.com/pgsty/kes/releases/tag/RELEASE.2026-10-25T00-00-00Z) 使用标签 `RELEASE.2026-10-25T00-00-00Z`，软件包版本为 `20261025000000.0.0`，源码提交为 [`b0a98d87f656`](https://github.com/pgsty/kes/commit/b0a98d87f6564c1a6d9584c0a5260910a731f66d)。这是 [10 月 25 日维护批次](/zh/blog/release/silo-20261025/)的独立组件版本，于 10 月 26 日发布。[下载页](/zh/download/#kes)已指向本版归档与软件包，配套 Docker Hub 多架构镜像（`linux/amd64`、`linux/arm64`）同步发布，固定版本标签与 `latest` 指向同一个已验收镜像。

## 工具链与依赖 {#dependencies}

相较 KES 20261018，本版将 Go 从 **1.27.2 升至 1.27.3**，更新 **25 个声明依赖模块**，并将 Windows 归档格式统一为 `.zip`：

| 依赖 | 已发布 KES 20261018 | 本版 |
| --- | --- | --- |
| AWS SDK v2 核心 | 1.47.3 | **1.47.4** |
| AWS SDK config / credentials | 1.33.9 / 1.20.9 | **1.33.10 / 1.20.10** |
| AWS Secrets Manager | 1.50.4 | **1.50.6** |
| Google Secret Manager | 1.22.0 | **1.23.0** |
| Google API / IAM | 0.304.0 / 1.14.0 | **0.308.0 / 1.15.0** |
| Google certificate proxy / GAX | 0.3.23 / 2.26.2 | **0.3.24 / 2.27.0** |
| HashiCorp go-rootcerts | 1.0.2 | **1.1.0** |
| Prometheus procfs | 0.22.0 | **0.23.0** |

其余更新包括 AWS 配套模块与三个 Google 生成 API 模块。10 月 25 日审计及 10 月 26 日复查覆盖全部 **26 个直接依赖、76 个间接依赖**以及模块图中的另外 93 个模块；所有声明依赖均已升至当前模块路径下的最新版本。

Lip Gloss v1 与 `gopkg.in/yaml.v3` 保留既有兼容版本（升级至 Lip Gloss v2 或切换 YAML 模块路径需单独验证终端输出与配置解析）。本版不改变 KES HTTP API、配置结构或已存密钥格式。

## 安全与打包 {#security}

Go 1.27.3 包含 `crypto/x509` 证书验证修复 **CVE-2026-111943 / GO-2026-6809**，详见[共享安全说明](/zh/blog/release/silo-20261025/#go-trust)。容器构建配方刷新了 UBI 9.8 基础镜像摘要，并沿用根证书阻断列表；若外部服务仍使用受阻断的根证书链，TLS 连接将被拒绝，详见[共享证书说明](/zh/blog/release/silo-20261025/#local-mitigations)。

使用 govulncheck 1.9.0 对 Linux、macOS、Windows 源码扫描均未发现受影响的已导入包（`golang.org/x/crypto` 中未导入的 OpenPGP 子包保留模块级 `GO-2026-5932` 记录）。基础镜像系统包说明见[共享 UBI 说明](/zh/blog/release/silo-20261025/#ubi-residuals)。

发布流水线将 GoReleaser 从 **2.18.3 升至 2.19.0**（[发行说明](https://github.com/goreleaser/goreleaser/releases/tag/v2.19.0)含 Go 1.27.3、依赖安全更新及归档错误处理修复）；nFPM 保持 **2.48.0**，由 CI 按 `go.mod` 指定的 Go 工具链构建。

Linux 与 macOS 归档使用 `.tar.gz`，Windows 归档改用 `.zip`。本版提供 6 个平台归档与 6 个 Linux RPM/DEB/APK 软件包；软件包安装 `/usr/local/bin/kes`，不会自动启动未配置的服务。

## 发布验收 {#validation}

源码 [`b0a98d87f656`](https://github.com/pgsty/kes/commit/b0a98d87f6564c1a6d9584c0a5260910a731f66d) 在打标签前通过了 [Go](https://github.com/pgsty/kes/actions/runs/40257613627)、[VulnCheck](https://github.com/pgsty/kes/actions/runs/40257613658)、[KMS Compatibility](https://github.com/pgsty/kes/actions/runs/40257613681) 和 [Test Release Pipeline](https://github.com/pgsty/kes/actions/runs/40257613626) 流水线，以及本地全量 Go race、vet、lint、模块完整性与发布保护脚本检查（云后端通过本地协议夹具测试）。

[Release 流水线](https://github.com/pgsty/kes/actions/runs/40258161919)产出 6 个平台归档、6 个 Linux 软件包及校验文件共 19 个附件。发布标签与两份 RPM 使用 Pigsty OpenPGP 密钥签名；归档、校验清单、DEB 和 APK 附带 GitHub 构建证明。发布前已下载核对二进制版本、源码标记、依赖版本、软件包内容与许可证文件。

维护栈兼容矩阵覆盖 OpenBao KV v2、Moto Secrets Manager 与 SILO **20261018、20260916、20260903**（以及 **SILO 20261025 Draft** 与 **mcli 20261025**）。OpenBao 测试以验证过 GitHub 构建证明的 KES 20261018 正式二进制为升级基线，Moto 测试保留 PGSTY AWS SDK v1 基线。两套测试均覆盖升级、回退与冷重启，并在每次切换时重启 SILO 以清空密钥缓存；升级前后写入的对象在回退与冷重启后均可正常解密，已存密钥在测试清理后保持完好。

KES 默认发布分支为 `master`，同一源码已同步至 `main`。
