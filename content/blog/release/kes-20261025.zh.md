**KES 20261025000000 已发布。** [GitHub Release](https://github.com/pgsty/kes/releases/tag/RELEASE.2026-10-25T00-00-00Z) 使用标签 `RELEASE.2026-10-25T00-00-00Z`，软件包版本为 `20261025000000.0.0`，源码为 [`b0a98d87f656`](https://github.com/pgsty/kes/commit/b0a98d87f6564c1a6d9584c0a5260910a731f66d)。这是 10 月 25 日维护批次的版本，实际于 10 月 26 日发布。[下载页](/zh/download/#kes) 已指向本版归档和软件包。配套 Docker Hub 镜像已发布，支持 `linux/amd64` 与 `linux/arm64`；固定版本标签与 `latest` 指向同一个已验收镜像。

KES 是可选、独立发布的服务。本版属于 [10 月 25 日维护批次](/zh/blog/release/silo-20261025/)，KES 的发布不代表 SILO Server 或 Console 已完成发布验收。

## 工具链与依赖 {#dependencies}

相较 KES 20261018，本版将 Go 从 **1.27.2 升至 1.27.3**，更新 **25 个声明依赖模块**。这些依赖改动此前已经提交至 KES 的 `main` 分支；本次发布准备对其复验，并纳入 Windows ZIP 归档改动。

| 依赖 | 已发布 KES 20261018 | 本版 |
| --- | --- | --- |
| AWS SDK v2 核心 | 1.47.3 | **1.47.4** |
| AWS SDK config / credentials | 1.33.9 / 1.20.9 | **1.33.10 / 1.20.10** |
| AWS Secrets Manager | 1.50.4 | **1.50.6** |
| Google Secret Manager | 1.22.0 | **1.23.0** |
| Google API / IAM | 0.304.0 / 1.14.0 | **0.308.0 / 1.15.0** |
| Google certificate proxy / GAX | 0.3.23 / 2.26.2 | **0.3.24 / 2.27.0** |
| HashiCorp go-rootcerts | 1.0.2 | **1.1.0** |
| Prometheus procfs | 0.22.0 | **0.23.0** |

其余更新包括 AWS 配套模块与三个 Google 生成 API 模块。10 月 25 日审计及 10 月 26 日复查覆盖全部 **26 个直接依赖、76 个间接依赖**，以及选定模块图中的另外 93 个模块。所有声明依赖均已达到 Go 在其现有模块路径下选出的最新版本。仅出现在模块图中、未被 KES 及其测试导入的模块，由所属上游依赖推进。

Lip Gloss v1 与 `gopkg.in/yaml.v3` 保留既有兼容版本。迁移至 Lip Gloss v2 或维护中的 YAML 导入路径，需要单独完成终端输出及配置迁移验证。本版不改变 KES HTTP API、配置结构或已存密钥格式。

## 安全与打包 {#security}

Go 1.27.3 包含 `crypto/x509` 证书验证修复 **CVE-2026-111943 / GO-2026-6809**，详见[共享安全说明](/zh/blog/release/silo-20261025/#go-trust)。容器构建配方更新 UBI 9.8 基础镜像摘要，并采用此前记录的根证书阻断列表。这一信任库缓解范围更广，仍使用被阻断根证书链的服务可能连接失败，详见[共享证书说明](/zh/blog/release/silo-20261025/#local-mitigations)。

使用 govulncheck 1.9.0 对 Linux、macOS、Windows 进行源码扫描，均未发现受影响的已导入包。`golang.org/x/crypto` 中未使用的 OpenPGP 包仍有模块级 `GO-2026-5932` 记录；这不代表整个模块图或容器镜像没有漏洞。系统包限制见[共享 UBI 说明](/zh/blog/release/silo-20261025/#ubi-residuals)。

发布流水线将 GoReleaser 从 **2.18.3 升至 2.19.0**，其[发行说明](https://github.com/goreleaser/goreleaser/releases/tag/v2.19.0)包含 Go 1.27.3、依赖安全更新及归档错误处理修复。nFPM 保持当前的 **2.48.0**，CI 使用 `go.mod` 指定的 Go 工具链构建。

Linux 与 macOS 归档继续使用 `.tar.gz`，Windows 归档改用 `.zip`。本版提供六个平台归档及六个 Linux RPM/DEB/APK 软件包，校验文件、RPM 签名及 GitHub 构建证明沿用现有发布流程。软件包安装 `/usr/local/bin/kes`，不会启动尚未配置的服务。

## 发布验收 {#validation}

源码 [`b0a98d87f656`](https://github.com/pgsty/kes/commit/b0a98d87f6564c1a6d9584c0a5260910a731f66d) 在打标签前，通过了发布分支 push 触发的 [Go](https://github.com/pgsty/kes/actions/runs/40257613627)、[VulnCheck](https://github.com/pgsty/kes/actions/runs/40257613658)、[KMS Compatibility](https://github.com/pgsty/kes/actions/runs/40257613681) 和 [Test Release Pipeline](https://github.com/pgsty/kes/actions/runs/40257613626)。本地全量 Go race、vet、lint、模块完整性与 tidy、品牌及发布保护脚本检查也已通过。云后端使用本地协议测试，不代表真实 AWS、GCP、Azure 账号验收。

[Release 流水线](https://github.com/pgsty/kes/actions/runs/40258161919)提供六个平台归档与六个 Linux 软件包，加上校验文件共 19 个下载附件。发布标签及两份 RPM 使用 Pigsty OpenPGP 密钥签名；归档、归档校验清单、DEB 和 APK 具有 GitHub 构建证明。正式发布前已下载核对二进制版本、干净源码标记、依赖版本、软件包内容和授权文件。

维护栈兼容矩阵覆盖 OpenBao KV v2、Moto Secrets Manager 与 SILO **20261018、20260916、20260903**。OpenBao 以正式 PGSTY KES 20261018 二进制为升级基线，使用前核对归档及校验清单的 GitHub 构建证明；Moto 保留 PGSTY AWS SDK v1 基线。两套测试都覆盖升级、回退和重启，每次切换都重启 SILO，避免密钥缓存掩盖读回故障。未修改的上游 KES 升级检查仍为尽力兼容项。

下载的 KES 正式制品还与实际 **SILO 20261025 Draft**、已发布的 **mcli 20261025** 二进制组合，通过了这两套后端测试。升级前后写入的对象在回退及服务端冷重启后均能解密，已存密钥在测试清理后保持不变。这些本地测试覆盖协议与版本兼容性，不证明后端崩溃持久性。

KES 继续使用 `master` 作为默认发布分支，同一源码也已同步到 `main`。GitHub Release 与 Docker Hub 是分别交付的制品。本次 KES 发布不发布 SILO Server，也不改变其存储一致性限制。
